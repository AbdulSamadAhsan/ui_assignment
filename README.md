# Fintech Landing Page

Responsive fintech landing page built with HTML, CSS, and JavaScript.

[Live deployment](https://ui-assignment-liard.vercel.app)

## Overview

- Responsive page layout
- Mobile navigation toggle
- Custom typography and visual assets

## View locally

Clone the repository and open `index.html` in a browser, or serve the repository through a local static web server. No dependency installation or build step is required.

## Scope

Frontend interface project; backend services are not included.
